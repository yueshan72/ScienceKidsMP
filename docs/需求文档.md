## 1. 产品概述

### 1.1 背景

市面上的儿童科普产品多以「纯刷视频」为主，缺少让孩子动手参与和系统留存的体验。团队希望做一款主打科普的儿童产品，用小程序承载互动体验，并通过科普周边（玩具/图书）实现变现。

### 1.2 产品定位（一句话）

> 一个分龄的儿童科普内容 + 互动体验平台：抖音短视频引流，小程序互动留存，科普周边电商变现。

### 1.3 核心闭环

```
抖音短视频（引流）
        ↓
小程序互动体验（留存：动手实验 + 闯关 + 打卡）
        ↓
精选联盟带货（变现：科普玩具 / 图书）
```

### 1.4 V1.0 要验证什么（目标）

- 验证「短视频引流 → 小程序留存 → 电商成交」全链路是否跑通。
- 验证一个爆款主题（太空/宇宙）能否同时承载内容吸引力和带货能力。
- 验证孩子/家长对「互动实验闯关」的接受度与留存情况。

## 2. 目标用户与分龄

| 年龄段 | 内容难度 | 主导交互 | 家长诉求 | 可带货商品 |
| --- | --- | --- | --- | --- |
| 3-6 学前 | 认知 / 观察 | 家长陪伴、语音引导、动画 | 安全打发时间、磨耳朵 | 太空绘本、星空投影灯 |
| 6-9 低年级 | 现象 / 原理入门 | 半自主、图文 + 短视频 | "学到点东西"、培养兴趣 | 望远镜、航天拼装模型 |
| 9-12 高年级 | 原理 / 动手探究 | 自主、闯关 / 实验 | 兴趣深化、素养提升 | 进阶实验套装、天文望远镜 |

V1.0 的「分龄」先做轻量版：用户首次进入选择年龄段，首页按年龄段推荐内容；同一主题（太空）按年龄给不同难度的内容。

## 3. V1.0 产品范围（MVP 收敛）

### 3.1 本期包含（In Scope）

1. 短视频科普：太空主题短视频内容的展示与播放（承接抖音引流）。
2. 互动实验闯关：太空主题的 3-5 个互动实验关卡，含闯关进度与奖励。
3. 精选联盟带货：主题相关商品的展示与跳转下单（佣金模式）。
4. 分龄入口：首次进入选择年龄段，首页按年龄分层推荐。
5. 轻量用户体系：登录、年龄标签、闯关进度、打卡记录。

### 3.2 本期不包含（Out of Scope）

- AI 问答互动（二期）。
- 图文 + 音频绘本（二期）。
- 自营商品 / 供应链（三期，先联盟带货）。
- 多端发布（微信小程序，三期）。
- 复杂推荐算法（V1.0 用「年龄 + 规则」推荐）。
- 家长社区 / UGC。

## 4. 核心功能需求

### 4.1 首页

- 年龄段选择：首次进入弹窗选择（3-6 / 6-9 / 9-12），可随时修改。
- 主题入口：太空主题大图入口，进入主题内容页。
- 内容流：按年龄段推荐短视频卡片列表。
- 我的入口：闯关进度、打卡、收藏。

### 4.2 短视频科普

- 太空主题短视频列表 + 播放页。
- 支持：点赞、收藏、全屏播放。
- 视频内容卡片下方关联商品位（如：视频讲"火箭原理" → 推荐火箭拼装模型）。
- 视频末尾引导：「去动手试一试」跳转对应实验关卡。

### 4.3 互动实验闯关（太空主题，核心留存）

设计 3-5 个关卡，孩子通过"点击/拖拽/选择"完成互动实验：

| 关卡 | 实验名 | 科普点 | 交互方式 |
| --- | --- | --- | --- |
| 1 | 火箭发射 | 反冲力原理 | 点击点火 → 观察火箭升空 |
| 2 | 陨石坑 | 撞击成坑 | 拖拽陨石砸向月面 → 看坑大小 |
| 3 | 行星排排队 | 太阳系顺序 | 拖拽行星到正确轨道 |
| 4 | 看星座 | 星座连线 | 点击星星连成星座图案 |
| 5 | 黑洞引力 | 引力概念 | 拖动小球靠近黑洞 → 被吸入 |

每关完成 → 获得星星奖励；全部完成 → 获得太空徽章。
支持连续打卡（连续完成天数记录，激励留存）。

### 4.4 电商带货（精选联盟）

- 每个实验关卡 / 视频的推荐商品位（1-2 个商品）。
- 商品信息：图片、标题、价格、佣金跳转。
- 跳转方式：抖音小程序购物车 / 精选联盟商品落地页。
- V1.0 太空主题候选商品：望远镜、航天拼装模型、太空绘本、星空投影灯、火箭积木。

### 4.5 轻量用户体系

- 登录方式：抖音授权登录（获取基础用户信息）。
- 用户数据：年龄标签、闯关进度、打卡记录、收藏列表。

## 5. 首个主题内容规划（太空 / 宇宙）

### 5.1 短视频内容清单（首批 8 条）

> **V1.1 统一**：原文写「8-10 条」但实际仅列出 8 条，《开发计划书》S4 亦为「首批 8 条」。现统一按 **8 条** 冻结，S4 内容生产按此数量排产。

1. 太阳系八大行星
2. 火箭是怎么飞上天的（反冲力）
3. 月球上的陨石坑
4. 宇航员在太空怎么生活
5. 黑洞是什么
6. 星座的由来
7. 地球为什么有白天黑夜
8. 火星上有没有外星人

### 5.2 带货商品位（首批）

- 每个视频 + 每个关卡挂 1-2 个相关商品（与 4.4 一致，首批先各挂 1 个）。
- 优先选抖音精选联盟中佣金高、口碑好、与主题强相关的商品。

## 6. 页面结构与信息架构

```
小程序
├── 首页（内容流 / 主题入口）
├── 主题内容页（太空）
│   ├── 短视频列表
│   ├── 互动实验闯关（关卡列表 → 关卡详情）

├── 闯关详情页（互动实验）
└── 我的
    ├── 年龄设置
    ├── 闯关进度 / 徽章
    ├── 打卡记录
    └── 收藏
```

## 7. 数据模型（核心实体）

| 实体 | 关键字段 |
| --- | --- |

| 主题 Topic | id、名称、封面、简介 |

## 8. 非功能需求

### 8.1 性能

- 首屏加载 ≤ 3 秒。
- 视频播放流畅（CDN 加速）。
- 关卡交互响应及时（无卡顿）。

### 8.2 安全与合规（生命线）

- 未成年保护：严格遵守抖音平台儿童内容规范。
- 内容审核：所有内容上线前过审，涉及科学准确性需审核。
- 隐私合规：不采集未成年人敏感信息，数据最小化。
- 广告合规：带货内容明确标识，不诱导消费。

### 8.3 技术选型（V1.1 定稿）

| 模块 | 选型 | 说明 |
| --- | --- | --- |
| 前端 | **抖音小程序原生** | 已定稿，不使用 Taro；理由见《开发计划书》1.1 |
| 后端 | 抖音云开发（CloudBase） | 云函数 + 云数据库 + 云存储 |
| 内容存储 | 云存储 + CDN | 承载视频 / 音频 / 图片 |
| 电商 | 抖音开放平台「小程序购物车 / 精选联盟」 | 不自建商品体系 |
| 登录 | 抖音授权登录 | 获取基础用户信息 |
| 内容安全 | 抖音内容安全接口 + 人工审核 | 上线前强制过审 |

> **V1.1 统一**：原文本节为「建议」，前端写作「原生（或 Taro 编译到抖音）」，并在第 12 节把选型留作待定；而《开发计划书》第 1 节已将其定为「技术路线总览（定稿）」并明确选择原生、否掉 Taro。现统一为定稿口径，两份文档不再冲突。

## 9. 产品约束与规范

### 9.1 法律合规约束（硬性，不可违背）

- 儿童个人信息保护：涉及 14 周岁以下未成年人，须遵守《个人信息保护法》及《儿童个人信息网络保护规定》：
  - 信息最小化收集，仅采集产品必需的数据；
  - 获取监护人同意后方可处理儿童个人信息；
  - 不将儿童个人信息用于精准广告或营销；
  - 提供删除、更正、撤回同意的入口。
- 平台内容合规：严格遵守抖音平台儿童内容专项规范，所有内容上线前强制过审。
- 广告合规：带货内容显著标识，禁止诱导性、夸大性消费引导。

### 9.2 科学准确性约束

- 科普内容必须事实准确、表述严谨，不得传播错误或未经验证的知识。
- 所有科普内容（视频脚本、关卡文案、实验结论）须经内容审核环节：至少一名具备相关学科背景的审核人（或科学顾问）确认。
- 涉及争议性科学话题（如"外星人""黑洞"）须标注"科学假设/未定论"，避免误导。

### 9.3 范围冻结与变更约束

- V1.0 需求评审通过后即冻结，不再新增功能点。
- 任何新增需求进入 V1.1 / V2 需求池，不得往 V1.0 内插队。
- 确需调整时，须经团队评审确认并同步更新本文档，禁止口头变更。

### 9.4 技术与性能约束（可量化验收）

- 平台/版本：明确抖音小程序最低支持版本、主流机型适配范围。
- 性能指标：首屏加载 ≤ 3s；视频起播 ≤ 2s；关卡交互无肉眼可见卡顿。
- 视频规范：统一码率、清晰度、时长上限，避免加载过慢与流量浪费。
- 稳定性：核心流程（登录、播放、闯关、下单）崩溃率 ≤ 0.5%。

### 9.5 数据与埋点约束

- 可采集：仅采集产品功能所需数据（年龄标签、闯关进度、打卡、收藏、转化埋点）。
- 不可采集：未成年人精确位置、联系方式等敏感信息；不用于跨平台追踪。
- 埋点规范：统一事件命名规则（如 page_xxx / click_xxx / complete_xxx ），新增埋点须登记，避免后期数据混乱。
- 数据留存：按合规要求设定数据留存期限，超出即删除/匿名化。

## 10. 埋点与核心指标

| 指标类型 | 具体指标 |
| --- | --- |
| 获客 | 短视频曝光、点击进小程序转化率 |
| 留存 | 次日留存、7 日留存、连续打卡率 |
| 互动 | 关卡完成率、人均完成关卡数 |
| 变现 | 商品点击率、成交转化率、佣金收入 |
