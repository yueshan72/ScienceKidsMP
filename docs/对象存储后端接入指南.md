## 0. 为什么走 TOS

| 项 | 文档型数据库 | 对象存储 TOS |
| --- | --- | --- |
| 开通 | 需「体验权限」审批，已等 9 天未通过 | 组件中心点「启用」即可，**无审批** |
| 本项目用量 | 3 个集合 | 每用户 3 个 JSON 文件，几 KB |
| 成本 | 免费（但拿不到权限） | 存储 0.099 元/GiB/月 + 请求 0.01 元/万次，课程用量≈0 |
| 客户端接口 | 不变 | **不变**（还是 `data-service` → `request.js`） |

TOS 不是"假数据库"：同名对象覆盖写就是保存，读回来就是整份用户状态。
V1.0 是单用户课堂演示，没有并发写压力，够用；真正的跨设备并发同步不在本期范围。

## 1. 控制台：启用对象存储

1. 登录**抖音云控制台**，选择应用（`scitest`）和环境（dev）。
2. 进入 **组件中心** → 找到 **对象存储** → 点 **启用**。
   - 首次启用会自动创建一个默认桶（Bucket）。
   - 记下 **桶名**（Bucket Name）和 **地域**（Region，通常是 `cn-beijing`）。
3. 进入对象存储页面，确认桶的读权限是 **私有读**。
   - 客户端不直接访问 TOS，私有读不影响使用；**不要**改成公开读。
4. 生成访问密钥：对象存储 → **访问密钥** → 新建。
   - 记下 **Access Key ID** 和 **Secret Access Key**。
   - Secret 通常只显示一次，先复制到安全位置；**不要**发到群里、不要提交进 git。

> 如果控制台没有「启用」按钮，或提示需要付费/实名：先看页面提示；
> 抖音云首次开通通常有体验代金券，课程用量不会产生可观费用。

### 1.1 Endpoint 怎么选

| 场景 | `TOS_ENDPOINT` |
| --- | --- |
| 云函数与桶同地域（推荐） | 控制台显示**内网 Endpoint**，填主机名，如 `tos-cn-beijing.ivolces.com` |
| 找不到内网 Endpoint | 公网 `tos-cn-beijing.volces.com`，并临时开启云函数「外网出流量」 |

> 控制台「对象存储域名」一栏显示的是**桶访问域名**（`桶名.tos-cn-beijing.volces.com`），
> 它用于浏览器/控制台访问，**不是** SDK 的 `endpoint`。`TOS_ENDPOINT` 只填到地域级主机名：
> `tos-cn-beijing.volces.com` 或内网 `tos-cn-beijing.ivolces.com`。

- 用内网 Endpoint 时，云函数的「外网出流量」可以保持**关闭**。
- 用公网 Endpoint 时，需要把云函数访问控制改成「非固定公网 IP」并发布；
  测试流量只有几 KB，费用可忽略，但演示完建议关回去。

## 2. 部署 `api` 云函数

新函数在 `cloudfunctions/api/`，一个函数承载 user / progress / checkin 三组 action。

### 2.1 上传

1. 开发者工具 → 抖音云 → 函数服务（沿用现有服务 `sciencekids` / dev 环境）。
2. 新增函数 `api`，目录选 `cloudfunctions/api/`（或整包上传时包含该目录）。
3. 确认依赖已安装：
   - 根 `package.json` 已声明 `@open-dy/node-server-sdk` 和 `@volcengine/tos-sdk`；
   - 抖音云在线编辑器会按根 `package.json` 安装依赖：**选中 `package.json` 发布一次**即可，
     无需上传 `node_modules`（官方默认也会装 tos 相关包，本项目显式声明版本更稳）；
   - 若面板提供「安装依赖」按钮，也可直接点；
   - 只有平台确实不装依赖时，才需要本地 `npm install` 后整包上传（zip ≤ 256 MiB，入口文件在 zip 根目录）。
4. 发布到 **dev**。
5. 右键函数 →「复制小程序端调用示例」，确认路径。
   - 预期是 **`/api/index`**；如果不同，以示例为准，并同步改 `miniprogram/app.js` 的 `paths`（三条都指向它）。
6. 访问控制 → 授权路径，新增 **`/api/index`**（旧的 `/user/index` 等保留不动）。

### 2.2 服务设置：环境变量

进入函数服务的 **服务设置 → 环境变量**，添加：

| 变量 | 必填 | 示例 | 说明 |
| --- | --- | --- | --- |
| `TOS_BUCKET` | ✅ | `sciencekids-xxxx` | 第 1 步的桶名 |
| `TOS_ACCESS_KEY_ID` | ✅ | `AKLT...` | 访问密钥 ID |
| `TOS_ACCESS_KEY_SECRET` | ✅ | `...` | 访问密钥 Secret |
| `TOS_REGION` | ✅ | `cn-beijing` | 与桶同地域 |
| `TOS_ENDPOINT` | ✅ | `tos-cn-beijing.ivolces.com` | 只填主机名，不带 `https://`；内网优先，没有就填公网 |
| `TOS_PREFIX` | 可选 | `sciencekids` | 对象 key 前缀，默认就是 `sciencekids` |

> 环境变量名不支持 `-`，本项目全部用下划线。
> 改完环境变量后需要**重新发布/重启服务**才生效。

### 2.3 对象结构

每个用户三个对象：

```
sciencekids/{openid}/user.json
sciencekids/{openid}/progress.json
sciencekids/{openid}/checkins.json
```

示例 `progress.json`：

```json
{
  "openid": "xxx",
  "levels": {
    "rocket-1": {
      "levelId": "rocket-1",
      "topicId": "space",
      "status": "done",
      "stars": 3,
      "completedAt": 1760000000000
    }
  },
  "badges": [
    { "badgeId": "badge_space", "name": "太空探索者", "icon": "🏅", "earnedAt": 1760000000000 }
  ],
  "updatedAt": 1760000000000
}
```

## 3. 小程序端切换

`miniprogram/app.js` 的 `paths` 已经全部指向 `/api/index`：

```js
cloud: {
  mode: 'auto',                    // ← 部署并配好环境变量后改成 'auto'
  envID: 'env-dIAlSn9Fkv',
  serviceID: '1mh9na5bu8gm2',
  paths: {
    user: '/api/index',
    progress: '/api/index',
    checkin: '/api/index'
  }
}
```

步骤：

1. 确认 `cloud.mode` 改为 **`'auto'`**。
2. 重新编译。
3. 走完整演示（见第 4 节）。
4. 到 TOS 控制台看 `sciencekids/` 下是否出现当前用户的三个 JSON。

> 出问题先把 `mode` 改回 `'local'`，本地演示立刻恢复，不影响课堂。
> 旧文档库函数和旧路径都没动，随时可以切回去（前提是数据库审批恢复）。

## 5. 成本与安全

**成本**（参考火山引擎 TOS 北京地域，实际以控制台为准）：

| 项 | 单价 | 本项目 |
| --- | --- | --- |
| 标准存储 | 0.099 元/GiB/月 | 数据 < 1 MB，≈0 |
| 请求 | 0.01 元/万次 | 演示几十次，≈0 |
| 内网流量 | 通常不计公网流量 | 用内网 Endpoint 时最省 |

**安全**：

- AK/SK **只放云函数环境变量**，不下发客户端、不写进 `app.js`、不提交 git。
- 桶保持**私有读**；客户端不直接访问 TOS，全部经云函数。
- 泄漏时立即在控制台禁用/删除密钥并重建。
- 如 IAM 支持，把密钥权限限制到该桶的对象读写（最小权限）。

**并发说明**：V1.0 每个用户只有一个客户端，按「读 → 改 → 覆盖写」处理；
严格的多端并发同步不在本期范围（与契约「收藏/点赞仅本地、不做跨设备同步」一致）。
