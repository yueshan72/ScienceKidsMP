## 七、本项目使用建议

- **暖色主题（3-6 / 6-9）**：不要用小白点 / 小星点铺在浅色背景上，容易像落灰。
  优先用奶油 → 浅粉紫的渐变 + 大尺寸柔光斑；需要图片时选真实星云图并加奶油色遮罩。
- **深色主题（9-12）**：保留深空背景 + 白色星点 / 星云；可以加一颗偶尔划过的流星。
- **包体控制**：背景图压缩到 600–800px 宽，JPEG / WebP；过大的图片放云存储，不要塞进代码包。
- **授权**：NASA 图片多数可用但不要用其标志；ESA / Hubble / ESO 逐张确认；Freepik / Flaticon 免费版署名。
- **答辩**：报告里标注素材来源和授权方式，避免“图片来源不明”。
