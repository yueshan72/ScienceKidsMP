# 「小宇宙科普」课堂演示脚本

> 版本：V1.0（2026-10-31）
> 时长：约 7 分钟（可按需删减到 5 分钟）
> 设备：一台手机（真机预览）+ 一台电脑（开发者工具 / 云数据库后台，可选）
> 演示模式：云端（`cloud.mode='auto'`）；断网时切备用本地版，见 §5

---

## 1. 演示目标（讲给老师听的三个点）

1. **分龄**：3-6 / 6-9 / 9-12，首页内容按年龄过滤。
2. **闭环**：短视频 → 互动闯关 → 打卡/徽章 → 我的，完整留存链路。
3. **合规**：监护人同意、删除数据、撤回同意三个入口齐全，且云端真的能清空。

技术一句话：抖音小程序原生 + 本地优先数据层 + 抖音云文档型数据库；云端失败自动回落本地，课堂演示不受网络影响。

## 4. 逐步操作与台词

### 4.1 开场（0:00–0:30）

**画面**：手机停在「需要监护人同意」页。

**台词**：
> 这是我们做的「小宇宙科普」，一个面向 3 到 12 岁孩子的分龄科普小程序，抖音端首发。
> 今天演示一条完整链路：监护人同意 → 选年龄 → 看视频 → 动手闯关 → 打卡拿徽章 → 数据删除与撤回。

### 4.2 监护人同意（0:30–1:00）

**操作**：点「查看并同意」→ 弹窗 → 点「同意并继续」。

**台词**：
> 因为面向儿童，第一次进入必须先由监护人同意。同意前不展示内容、也不采集任何数据。
> 我们只收集年龄段、闯关进度、徽章和打卡，不收集位置和联系方式。

### 4.3 分龄（1:00–1:30）

**操作**：选「3-6 岁 · 学前」→ 首页出现「当前年龄段：3-6 岁」。

**台词**：
> 选完年龄，首页内容会按年龄段过滤；同一个太空主题，不同年龄看到不同难度的内容。
> 年龄随时可以在「我的」里更正。

**可选动作**：点「修改」，展示年龄段弹窗，再取消；或留到后面 5:00 一起演示。

### 4.4 短视频（1:30–2:30）

**操作**：
1. 点「🚀 太空 / 宇宙」卡片 → 主题页
2. 点第一条视频「火箭为什么能飞上天？」
3. 播放 5–10 秒；点「点赞」→ 变「已赞」；点「收藏」→ 变「已收藏」
4. 点「去动手试一试」→ 直接进火箭关卡

**台词**：
> 视频页支持播放、点赞、收藏，右下角「推广」是带货位的合规标识。
> 视频末尾可以直接跳到对应实验，形成「看 → 动手」的闭环。
> 点赞和收藏在 V1.0 先存本地，后续再接云端。

### 4.5 互动闯关：火箭（2:30–4:00）

**操作**：
1. 关卡页提示「点一点下面的点火按钮，让火箭飞起来！」
2. 点下面的 🔥「点火按钮」
3. 火箭升空，出现「已通关 ★★★」
4. 可点「再试一次」演示一次重置（可选）

**台词**：
> 关卡不是看动画，而是要孩子真的操作：点对点火按钮才通关，点星星会提示再找找。
> 星级由云函数判定，前端只负责展示，不能自己给自己发奖励。
> 通关记录会同时写本地和云端，断网也不会丢。

### 4.6 我的：打卡与进度（4:00–5:00）

**操作**：
1. 底部切到「我的」
2. 展示「闯关进度」「连续打卡」「今日打卡」按钮
3. 点「今日打卡」→ 显示打卡成功，日历当天点亮
4. 展示「我的收藏」里刚才收藏的视频

**台词**：
> 「我的」汇总了进度、打卡、徽章和收藏。
> 打卡和通关都会同步到云端，换设备登录同一个抖音号可以接着用。
> 这里也是合规入口：更正年龄、删除数据、撤回同意。

### 4.7 更正年龄 + 第二、三关 + 徽章（5:00–6:00）

**操作**：
1. 「我的」→「更正年龄段」→ 选「9-12 岁 · 高年级」
2. 回首页 → 太空 → 点「陨石坑」
3. 点中两颗 ☄️（别点月亮）→ 通关
4. 返回主题页 → 点「寻找地球」
5. 在行星里点中 🌍（别点火星 / 木星 / 月球）→ 通关
6. 页面出现「🏅 获得徽章：太空探索者」
7. 回「我的」→ 徽章区显示「太空探索者」

> 徽章判定要求太空主题 **3 关全部通关**（火箭 / 陨石坑 / 寻找地球），少一关不会弹。

**台词**：
> 年龄可以随时更正，内容会立刻切换。
> 同一主题的三关全部通关后，才会发「太空探索者」徽章——奖励是云函数判定的，防止前端刷奖励。
> 徽章写在云端 `badges` 集合里，不是本地假数据。

> ⏱ 如果时间紧，可跳过本段，只展示火箭关卡；但徽章是留存亮点，建议保留。

### 4.8 删除数据 / 撤回同意（5:45–6:30）

**操作**：
1. 「我的」→「删除我的数据」→ 确认
2. 回到首页 → 弹出年龄段选择（注意：同意仍然保留）
3. 切回「我的」→「撤回监护人同意」→ 确认
4. 回到首页 → 显示「需要监护人同意」

**台词**：
> 删除数据只清业务数据，不会替用户撤回同意；删除后可以重新选年龄继续用。
> 撤回同意是更彻底的动作：停止处理、清空数据，并回到未同意状态。
> 这两个动作在云端都会真的删掉四张表里的记录，不是只清本地缓存。

**可选**：切到电脑上的云数据库，展示删除前后的记录变化（`users` / `progress` / `checkins` / `badges`）。

### 4.9 技术架构与收尾（6:30–7:00）

**台词**：
> 技术上用抖音小程序原生开发，数据层做了本地优先：先写本地，再异步同步云端，云端失败自动回落，所以课堂演示不怕断网。
> 后端是抖音云文档型数据库，四个集合：用户、进度、打卡、徽章；所有写操作都经云函数，前端不直接碰数据库。
> 我们还保留了对象存储方案作为备选，切换只改一行配置。
> 目前 348 项自动化测试全部通过，已在真机上跑通完整云端闭环。

## 5. 断网 / 异常兜底

### 5.1 网络不稳时

云写入失败会**自动回落本地**，看视频、闯关、打卡都能继续；但**删除 / 撤回是 fail-closed**，断网时会提示「删除失败」。

所以演示前先测网络：

- 正常 → 用云端版（`cloud.mode='auto'`）
- 会场网络不可靠 → 用**备用本地版**（`cloud.mode='local'`）

### 5.2 备用本地版怎么准备

在演示前（不是台上）：

1. 把 `miniprogram/app.js` 的 `cloud.mode` 改为 `'local'`
2. 编译 → 生成预览二维码 → 手机扫码确认能完整走通
3. 把二维码截图/保留在另一台设备
4. 改回 `'auto'`，重新编译，作为主演示版

> 本地版不发起任何云请求，删除 / 撤回都能正常完成。

### 5.3 常见异常

| 现象 | 处理 |
| --- | --- |
| 视频加载失败 | 提前确认素材已打包；现场用「素材准备中」卡片继续讲 |
| 云端写入失败（控制台有 warn） | 不影响页面演示；口头说明「已回落本地」 |
| 删除失败 | 说明是网络问题，切本地版演示该段 |
| 预览码过期 | 开发者工具重新生成，不要复用旧码 |

## 6. 可能被问到的问题

**Q：为什么不用微信小程序？**
A：课程要求抖音端首发；技术上原生开发，后续要扩微信可以用 Taro 迁移，成本可控。

**Q：数据存在哪里？**
A：抖音云文档型数据库，四个集合；客户端本地留一份镜像，读走本地、写同步云端。

**Q：儿童数据合规怎么保证？**
A：同意前不采集；只收年龄段、进度、打卡、徽章；提供删除、更正、撤回三个入口；删除/撤回云端真删。

**Q：视频为什么只有几条？**
A：V1.0 先验证播放链路和内容结构，首批 3-4 条演示素材，正式 8 条按内容排期补齐。

**Q：徽章为什么不是前端发的？**
A：奖励由云函数判定，避免前端改代码刷星刷徽章；这也是接口契约里明确的一条。
